# AISHA Product Requirements Documents

Each PRD uses the same product format:

1. Summary
2. Problem
3. Goals and non-goals
4. Users
5. Requirements mapped to user stories
6. Flow
7. Technical notes
8. Success metrics
9. Risks and open questions

The implementation tracker is [`jira.md`](./jira.md).
